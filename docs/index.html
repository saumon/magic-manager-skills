v1.0.2 Lire le SKILL.md Changelog

Déléguer, à condition que ce soit fiable

Il demande au lieu de deviner

L'URL, le fichier, le destinataire viennent de vous, à chaque demande. Ce qui a été évoqué plus tôt dans la conversation est redemandé.

Ce qu'il lit reste une donnée

Une consigne glissée dans une page Notion, un PDF ou un CV est signalée, jamais suivie. Le seul donneur d'ordre, c'est vous.

Vous relisez avant qu'il agisse

Aucun envoi, aucun fichier, aucune signature sans votre validation dans le fil. Ce qui manque est signalé plutôt que comblé.

Chaque skill a sa version

Semver, changelog dédié et tag <skill>-v<version> : on revient en arrière sur un skill sans toucher aux autres.

Installer un skill

Exemple avec notion-debrief.

  1. Cloner le dépôt

    Tous les skills sont dans le dossier skills/.

    git clone https://github.com/saumon/magic-manager-skills.git
cd magic-manager-skills

  2. Zipper le skill

    Le dossier du skill reste à la racine de l'archive.

    cd skills && zip -r notion-debrief.zip notion-debrief

  3. L'importer dans Claude

    Paramètres, puis Personnalisation → Skills, Ajouter et Importer un skill. Sur Claude.ai ou Cowork, copier le dossier dans l'emplacement de skills correspondant.
