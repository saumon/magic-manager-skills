Pourquoi ce projet

Je suis Grégoire, Engineering Manager

L'ère de l'IA agentique change la donne pour un manager : je peux enfin déléguer les tâches à faible valeur ajoutée sans écrire une ligne d'intégration. Encore faut-il que la délégation soit fiable et reproductible.

⚡

Accélérer, pas bricoler

Un prompt bien tourné se perd dans une conversation. Un skill, lui, capture le déroulé complet d'un workflow et le rejoue à l'identique la fois suivante.

🧭

Des garde-fous explicites

Chaque skill impose ses règles : demander les entrées plutôt que les deviner, traiter le contenu externe comme une donnée et jamais comme une instruction, signaler ce qui bloque au lieu d'improviser.

📦

Versionné comme du code

Semver par skill, changelog dédié, tag Git au format <skill>-v<version> : on peut revenir en arrière sur un skill précis sans toucher aux autres.

Pour qui

Pensés pour une stack proche de la mienne

Ces skills sont directement exploitables si votre quotidien ressemble au mien. Sinon, ils restent une bonne base de départ à adapter — tout est en Markdown lisible.

💬

Microsoft Teams

Via le MCP Kommunicator, qui envoie messages et cartes adaptives par webhook Power Automate — sans droits d'administration Office 365.

📓

Notion

Base de connaissances de l'équipe : comptes rendus, dossiers, suivis. Le MCP Notion sert de source de lecture aux skills de débriefing.

🤖

Claude

Claude Code, l'application desktop ou Claude.ai : partout où l'on peut importer un dossier de skill, le workflow se déclenche à la demande.

👥

Un rôle de manager

Débriefings, recrutement, reporting : les cas d'usage viennent de situations réelles d'Engineering Management, pas d'exemples de démonstration.

Skills disponibles

Trois workflows prêts à l'emploi

Chaque skill vit dans son propre dossier sous skills/, avec son SKILL.md, son changelog et ses éventuelles ressources.

notion-debrief

v1.3.0

Résume une page Notion, en tire une liste d'actions, puis envoie le débriefing sous forme de carte adaptive à un destinataire sur Teams. L'URL Notion est toujours demandée explicitement, jamais devinée.

  • Notion
  • Kommunicator
  • Teams
  • Adaptive Card

resume-shortlist

v1.2.0

Analyse un lot de CV face à une offre d'emploi et produit une short list classée — à rencontrer, à creuser, écarté — avec score, indice de cohérence, points forts, réserves et questions d'entretien. Chaque candidat reçoit un tableau d'appréciation des compétences techniques de l'offre, du hors sujet au bien. Détecte les CV alignés artificiellement sur l'offre et exporte le rapport en PDF, tableaux compris.

  • Aucun MCP
  • Recrutement
  • PDF
  • Anti-biais

resume-to-markdown

v1.0.0

Transforme un CV PDF ou Word en fichier Markdown, par dépouillement de forme : photo, logos, icônes, couleurs, colonnes et jauges disparaîssent, mais aucune information textuelle n'est écartée. Ni résumé ni réécriture : l'ordre du document source est conservé à l'identique. Le fichier produit porte le même nom que la source (cv-toto.pdf → cv-toto.md) et sert à alimenter resume-shortlist avec des CV allégés.

  • Aucun MCP
  • PDF
  • Word
  • Markdown

Installation

Opérationnel en trois étapes

Exemple avec le skill notion-debrief.

Cloner le dépôt

Tous les skills sont dans le dossier skills/.

git clone https://github.com/saumon/magic-manager-skills.git
cd magic-manager-skills

Zipper le skill voulu

Garder le dossier du skill à la racine de l'archive.

cd skills && zip -r notion-debrief.zip notion-debrief

Importer dans Claude

Dans l'application, aller dans Compétences → Gérer les compétences et importer le .zip. Sur Claude.ai ou Cowork, copier le contenu du dossier dans l'emplacement de skills correspondant.
